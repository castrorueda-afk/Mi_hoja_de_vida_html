# 🌐 Hoja de Vida Web - Responsive & GitHub Pages

Este proyecto consiste en una **Hoja de Vida Web** interactiva y responsive, construida desde cero y desplegada públicamente mediante GitHub Pages.

## 🔗 Enlace al Sitio Web
👉 **[Ver Sitio en Vivo](https://castrorueda-afk.github.io/mi-hoja-de-vida/)**

## 📂 Páginas del Sitio
- **`index.html`**: Página principal con perfil profesional, educación y habilidades técnicas.
- **`proyectos.html`**: Galería de proyectos académicos desarrollados en Python, HTML/CSS y PSeInt.
- **`contacto.html`**: Formulario de contacto seguro y directo.

## 🛠️ Tecnologías e Herramientas
- **HTML5**: Estructura semántica.
- **CSS3**: Layout con CSS Grid, Flexbox, variables CSS y Media Queries para diseño responsive.
- **Git & GitHub**: Control de versiones y despliegue automatizado con **GitHub Pages**.

## 🔒 Privacidad y Seguridad
En cumplimiento con las buenas prácticas de seguridad, el sitio **no contiene** datos personales sensibles (como número de identificación, dirección residencial ni teléfono personal).

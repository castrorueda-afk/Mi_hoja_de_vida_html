## 📁 Estructura del Proyecto
El sitio web está compuesto por tres páginas principales que comparten una misma hoja de estilos modular:
* `index.html` → Página principal (Perfil profesional, formación académica y habilidades técnicas).
* `proyectos.html` → Sección de proyectos destacados (Script de Python con JSON, algoritmos en PSeInt y maquetación web).
* `contacto.html` → Formulario de contacto funcional integrado con Formspree.
* `styles.css` → Hoja de estilos centralizada con variables CSS, diseño responsive (CSS Grid y Flexbox).

---

## 💻 Tecnologías y Herramientas Utilizadas
* **HTML5 Semantic:** Maquetación estructurada y accesible.
* **CSS3:** Estilos avanzados, diseño adaptable con *CSS Grid* y *Flexbox*.
* **Git & Terminal:** Control de versiones y gestión de ramas locales y remotas.
* **GitHub Pages:** Despliegue y alojamiento web gratuito.
* **Formspree:** Gestión de envío de correos desde el formulario de contacto.
